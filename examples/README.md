# Examples

- `claude-code.sh` — add ASR Memory to Claude Code.
- `antigravity-mcp.json` — Antigravity MCP config (Settings → MCP Servers → Open MCP Config), then click Authenticate.

Other clients (Claude, ChatGPT, Codex, Gemini, Hermes) connect from their settings screens with the address `https://asrmemory.com/mcp`. Step-by-step: https://asrmemory.com/en/docs.html
